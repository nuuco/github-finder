# 프롬프트 로그 (GitHub Finder)

이 문서는 이 프로젝트를 만들 때 AI에 요청한 내용과, 그 의도가 결과에 어떻게 반영되었는지 요약합니다.

## 1. 초기 요구 (와이어프레임·미션)

- **의도**: 단순 모방이 아니라 GitHub REST API로 실제 데이터를 받아 검색창·프로필·통계·저장소 목록·상태 메시지를 채운다.  
- **반영**: `users` + `repos` 엔드포인트 연동, 로딩·에러·빈 입력 처리, 저장소는 외부 링크.

## 2. 스택·검색 방식

- **의도**: 디바운스 자동 검색 없이 Enter/버튼만; 가능하면 HTML/CSS/JS만 사용.  
- **반영**: 바닐라 ES 모듈, 폼 submit만 API 호출, 번들러·프레임워크 없음.

## 3. 비인증·배포 범위

- **의도**: 토큰 없이 공개 API만 사용; GitHub Pages 배포는 계획에서 빼고 작성자가 나중에 처리.  
- **반영**: `Authorization` 헤더 없음, README는 로컬 실행 위주; 배포 스크립트는 포함하지 않음.

## 4. UX·문서

- **의도**: 초기 화면은 빈 상태, 저장소 링크는 새 탭, UI 문구는 한국어, README + 본 문서 링크.  
- **반영**: `index.html` 초기 카피, `target="_blank"` 및 `rel="noopener noreferrer"`, `README.md`와 본 파일.

## 5. 에러·보안

- **의도**: 404/403/네트워크 등 한국어 안내; XSS 주의.  
- **반영**: `main.js` 분기 메시지, `ui.js`에서 사용자 제공 문자열은 `textContent` 등으로 삽입.

## 6. 구현 실행 프롬프트 (요약)

- **의도**: 첨부 계획서대로 구현하고, 계획 파일은 수정하지 말 것. 할 일 목록을 순서대로 완료.  
- **반영**: 저장소에 `index.html`, `styles.css`, `js/*`, `README.md`, 본 문서, `AGENTS.md` 추가.
